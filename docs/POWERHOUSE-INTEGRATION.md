# Powerhouse Project Integration

ProjectForge AI is part of the Solo Service Provider development portfolio.

## Current functionality

Project planning, local-first workspaces, build briefs, prompts and **eight** starter applications. The v4 additions are GitHub Live Hub and Workflow Lab; see the [current tool index](../README.md#current-status--27-october-2026). This project does not currently provide model-backed generative AI, remote user sync or paid entitlements.

## Integration roadmap

- [ ] Add a clearly labelled external link from Powerhouse to the ProjectForge experience.
- [ ] Define an app manifest with title, description, icon, version, license and public launch URL.
- [ ] Reuse the shared industrial brand tokens while retaining product accessibility.
- [ ] Keep user workspace data local until an explicitly designed authenticated sync service is introduced.
- [ ] Assess app-store packaging and installability separately.
- [ ] Review licensing, checkout and customer support before commercial listing.

Do not advertise this repository as a paid standalone app until the release gates are met.
